# مكتبة مِسْك القرآنية

موقع ثابت جاهز للنشر على GitHub Pages (لا يحتاج إلى بناء أو تثبيت أي حزم).

## النشر
1. ارفعي كل محتويات هذا المجلد إلى جذر المستودع (يجب أن يكون `index.html` في الجذر مباشرة).
2. من المستودع: Settings ← Pages ← Source: **Deploy from a branch** ← Branch: **main** و **/(root)** ← Save.
3. بعد دقيقة تقريبًا يظهر الرابط: `https://اسم-المستخدم.github.io/اسم-المستودع/`

## التحديث
- لتغيير الروابط أو العناوين: عدّلي القسم المعلَّم «المحتوى» في أعلى الشيفرة داخل `index.html`.
- رابط مجلد الاختبارات: المتغيّر `EXAMS_URL`.
- ملفات الدروس صور داخل `docs/`، والتنزيل يُنشأ منها تلقائيًا.

## التثبيت على الهاتف
- أندرويد (Chrome): زر «تثبيت على الهاتف» في الموقع، أو ⋮ ← تثبيت التطبيق.
- آيفون (Safari): زر المشاركة ← إضافة إلى الشاشة الرئيسية.
