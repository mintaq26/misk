# مسك — مكتبة مِسْك القرآنية (تطبيق ويب قابل للتثبيت)

## الرفع على GitHub (مرة واحدة)
1. أنشئ مستودعًا جديدًا (مثلًا `masak`) على github.com.
2. ارفع **كل** محتويات هذا المجلد إلى الفرع `main` (بما فيها مجلد `.github` و`icons`).
3. من المستودع: Settings ← Pages ← Source ← اختر **GitHub Actions**.
4. بعد دقيقة يظهر الرابط: `https://اسم-حسابك.github.io/masak/`

## التثبيت على الهاتف
- **أندرويد (Chrome):** افتح الرابط ← القائمة ⋮ ← «تثبيت التطبيق».
- **آيفون (Safari فقط):** افتح الرابط ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

بعد أول فتح بالإنترنت يعمل التطبيق دون إنترنت (الخطوط تُحفظ عند أول تحميل).

## تحديث المحتوى لاحقًا
عدّل `index.html` ثم غيّر رقم `VER` في `sw.js` (مثل `masak-v2`) ليصل التحديث للأجهزة.
